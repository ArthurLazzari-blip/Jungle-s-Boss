#Jungle's Boss

Jogo web 2D de plataforma desenvolvido em HTML5 e JavaScript utilizando Phaser 3.

##Integrantes do Grupo
- Arthur Lazzari
- Leonardo

##Descricao do Jogo
Em Jungle's Boss, o jogador controla um explorador que deve percorrer os cenários, coletar bananas com gravidade e quique, desviar de obstáculos de fogo animado e derrotar o chefão Monkeyko.

##Controles
- Seta para Esquerda: Mover o personagem para a esquerda (com espelhamento de sprite).
- Seta para Direita: Mover o personagem para a direita.
- Seta para Cima: Pular.
- Tecla Espaco: Iniciar o jogo no menu principal.

##Requisitos Minimos
- Navegador com suporte a HTML5, JavaScript e Canvas.
- Conexao com a internet para carregar a biblioteca Phaser via CDN.

##Tecnologias Utilizadas
- HTML5 e CSS3
- JavaScript (ES6+)
- Phaser 3 (Arcade Physics)
